# AI Agent API Demo

## Overview

This project is a small, production-shaped demonstration of an AI agent behind a REST API:

```text
Client
  -> Express REST API
  -> Hello World AI Agent
  -> NVIDIA NIM (OpenAI-compatible)
  -> AI response
  -> REST API
  -> Client
```

The API layer validates requests and handles HTTP concerns. The agent owns the AI instructions and NVIDIA API call. Keeping those responsibilities separate makes it easy to replace the demo agent later.

## Features

- REST API built with Express
- NVIDIA NIM through the official OpenAI Node.js SDK
- Modular agent architecture
- Environment-based secrets and model configuration
- Health endpoint
- Request validation and safe error handling
- CORS support
- Responsive browser chat interface built with HTML, CSS, and JavaScript

## Requirements

- Node.js 18 or newer
- An NVIDIA API key with API access enabled

## Installation

```bash
cd openai-agent-demo
npm install
```

## Environment Setup

Copy `.env.example` to `.env`, then set your API key:

```dotenv
NVIDIA_API_KEY=your_nvidia_api_key_here
NVIDIA_MODEL=nvidia/nemotron-3-super-120b-a12b
NVIDIA_BASE_URL=https://integrate.api.nvidia.com/v1
PORT=5000
```

`NVIDIA_MODEL` and `NVIDIA_BASE_URL` are configurable. The default model is `nvidia/nemotron-3-super-120b-a12b`, which has a currently available NVIDIA-hosted endpoint. Never commit `.env` or place a real key in source code.

## Run

Development mode with automatic restart:

```bash
npm run dev
```

Normal mode:

```bash
npm start
```

The server runs at `http://localhost:5000` unless `PORT` is changed.

## Endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/` | Opens the browser chat interface |
| GET | `/api` | Confirms that the API is running |
| GET | `/health` | Returns service health |
| GET | `/api/status` | Shows the provider, model, and whether a key is configured |
| POST | `/api/chat` | Sends a message to the Hello World agent |

### Example

Request:

```json
{
  "message": "Hello World"
}
```

Successful response:

```json
{
  "success": true,
  "response": "Hello! How can I help you today?"
}
```

The response text is generated by NVIDIA and will vary.

### curl (macOS/Linux)

```bash
curl http://localhost:5000/health

curl -X POST http://localhost:5000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"Hello World"}'
```

### curl (Windows PowerShell)

```powershell
curl.exe http://localhost:5000/health

curl.exe -X POST http://localhost:5000/api/chat `
  -H "Content-Type: application/json" `
  -d '{"message":"Hello World"}'
```

PowerShell-native alternative:

```powershell
Invoke-RestMethod -Method Post `
  -Uri http://localhost:5000/api/chat `
  -ContentType "application/json" `
  -Body '{"message":"Hello World"}'
```

## Validation and Errors

- A missing, empty, or non-string `message` returns HTTP 400.
- Invalid JSON returns HTTP 400.
- A missing API key returns HTTP 503 without exposing configuration details.
- Authentication, retired-model, provider-limit, and unexpected NVIDIA failures are mapped to safe responses without exposing secrets or stack traces.

## Architecture

- `src/server.js` configures Express, middleware, routes, endpoints, and final error handling.
- `src/routes/chat.js` validates HTTP input, invokes the agent, and maps failures to safe HTTP responses.
- `src/agents/helloAgent.js` contains the demo agent instructions and calls NVIDIA's OpenAI-compatible chat completions API.
- `src/config/openai.js` validates the NVIDIA configuration and creates the official OpenAI client with NVIDIA's compatible base URL only when the chat endpoint needs it.
- `public/` contains the responsive browser interface that sends messages to the REST API.

## Future Extension

The isolated `helloAgent(message)` function can later be replaced by `businessAgent(message)`, `customerSupportAgent(message)`, or `leaveManagementAgent(message)`. The server and API contract can remain unchanged while the instructions and business behavior evolve inside the agent module.
